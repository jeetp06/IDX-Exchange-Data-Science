# Drop your authorized CRMLS sold data here

Download a minimum of six **completed** months of files with names beginning `CRMLSSold` from the approved IDX Exchange FileZilla server. Use only the authorized `/raw/California` source; **copy/download, never edit the original raw files**. The loader supports `.csv`, `.csv.gz`, and `.parquet` with CSV column names from Trestle; contact your supervisor if files use another format.

No MLS records are included here. Do not upload these data files to a public GitHub repository. `.gitignore` excludes this directory. The FTP credentials are deliberately not stored in this project.
